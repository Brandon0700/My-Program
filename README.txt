MY PROGRAM — FREE GYM APP

Included:
- Five-day Push / Pull / Legs / Upper / Lower split
- Warm-ups and cool-downs for every workout
- Cardio spread across Pull and Upper days
- Core work spread across Push and Legs days
- No extra cardio/core block on Lower day, helping protect recovery
- Exercise logging (sets, reps, weights)
- 12-week programme with a week 9 deload
- Bodyweight tracker with regular entries and check-ins at weeks 4, 8 and 12
- Workout history, volume totals and exercise-weight personal records
- Local browser storage and installable PWA files

Publish free from an iPhone:
1. Save and extract this ZIP in the iPhone Files app.
2. Open github.com in Safari and create a free account/sign in.
3. Create a public repository named my-program.
4. Upload index.html, manifest.webmanifest, sw.js and icon.svg to the repository root.
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait for GitHub Pages to publish and open the URL it provides.
9. In iPhone Safari, tap Share > Add to Home Screen > Add.

Data is stored locally in Safari on this device, not synced to an account or cloud. Avoid clearing Safari website data if you want to keep it. The programme is a general training template; adapt loads and exercises to your ability and recovery.
